§2 시간축의 불일치 · DATAFRAME INDEXING TRANSFORMATION

실제 테이블에서 set_index('Date')가 일어날 때의 물리적 변화

read_csv() 직후에는 Date가 단순한 데이터 열 중 하나에 불과합니다. 아래 스텝 버튼을 눌러, 일반 열이었던 Date가 왼쪽의 행 라벨(Index) 자리로 슬라이딩되어 이동하고 테이블 형태가 재구조화되는 과정을 확인하세요.

DataFrame 변형 단계: 현재: 일반 DataFrame (RangeIndex)
samsung = pd.read_csv('samsung_005930.csv') | shape: (120, 3) | Index: RangeIndex(0, 120)
Index Date (일반 컬럼) Close Volume
0 '2026-01-02' <str> 63,500 12,450,000
1 '2026-01-05' <str> 63,800 10,120,000
2 '2026-01-06' <str> 64,100 15,300,000
3 '2026-03-04' <str> 65,200 14,100,000
상태 설명: read_csv() 직후에는 왼쪽 행 번호가 단순 정수(0, 1, 2, 3...)이고, Date는 문자열 타입의 데이터 열 중 하나입니다.

💻 §500-1 ~ §500-2 파이썬 실행 코드

import pandas as pd

# 1. 파일 읽기 (Date 열은 문자열)
samsung = pd.read_csv('data/samsung_005930.csv')
print(type(samsung['Date'].iloc[0]))
# 출력: <class 'str'>

# 2. DatetimeIndex로 승격
samsung['Date'] = pd.to_datetime(samsung['Date'])
samsung = samsung.set_index('Date')
print(samsung.index[:3])
# 출력: DatetimeIndex(['2026-01-02', '2026-01-05', '2026-01-06'])

🔍 테이블 형태 변화의 핵심 요약

  • 기존 정수 인덱스 소멸: 의미 없는 숫자 행 번호(0, 1, 2)가 사라지고 실제 날짜가 행의 유일한 식별자가 됩니다.
  • 컬럼 수 감소 (3열 → 2열): Date가 인덱스로 빠져나가면서 데이터 열(Columns)에는 순수한 수치 데이터(Close, Volume)만 남습니다.
  • 달력 연산 잠금 해제: 이제부터 samsung.index.month나 samsung.loc['2026-03'] 같은 강력한 날짜 연산이 가능해집니다.
§3 좌표계로서의 날짜 · PERIOD SLICING

§4 & §5 두 테이블의 결합 · TABLE MERGE ANIMATION

🎨 학생을 위한 4대 조인(Join) 벤다이어그램 인터랙티브 랩

버튼을 클릭하면 결합 영역과 Pandas 데이터프레임의 행 수가 실시간으로 반응합니다
조인 방식(how) 선택:
how='inner' (교집합) shape: (120, 2) | NaN: 0개

둘 다 존재하는 날짜만 남긴다 (교집합)

삼성전자와 환율 모두에 존재하는 120일만 남깁니다. 결측치(NaN)는 0개라 겉보기엔 깔끔하지만, 환율만 존재했던 8일의 소중한 외환 데이터가 영구히 소실됩니다.

실행 파이썬 코드:
pd.merge(samsung, usdkrw, left_index=True, right_index=True, how='inner')

💻 §500-7: how='inner' (데이터 유실)

inner = pd.merge(
    samsung[['Close']].rename(columns={'Close': 'Samsung'}),
    usdkrw[['Close']].rename(columns={'Close': 'USDKRW'}),
    left_index=True, right_index=True, how='inner'
)
print(inner.shape)          # (120, 2)
print(inner.isnull().sum())  # Samsung: 0, USDKRW: 0
# NaN은 없지만 환율 8일치 데이터가 완전히 삭제됨!

💻 §500-8: how='outer' (정직한 보존)

outer = pd.merge(
    samsung[['Close']].rename(columns={'Close': 'Samsung'}),
    usdkrw[['Close']].rename(columns={'Close': 'USDKRW'}),
    left_index=True, right_index=True, how='outer'
)
print(outer.shape)          # (128, 2)
print(outer.isnull().sum())  # Samsung: 8, USDKRW: 0
# 128일 모두 살리고, 삼성전자가 쉰 8일만 NaN으로 보존!
§6 결측치의 인과적 정체 · 8 GAP DATES

gap_dates = outer[outer['Samsung'].isnull()].index (정확히 8일 전수 일치)

§7 결측치 채우기의 함정 · CELL-BY-CELL SIMULATOR

가격 ffill은 상식이고, 수익률 ffill은 위험한 조작이다

§8 다중 자산 통합 파이프라인 · THREE ASSET JOIN

세 자산을 한 표 위에 — (128, 3) 통합 마스터 테이블

삼성전자, NAVER, 환율 3개 자산을 2회 연속 merge(how='outer')로 도킹합니다. 국내 두 주식(삼성, NAVER)은 동일한 거래소 휴장일을 따르므로 정확히 같은 날짜에 나란히 NaN이 발생합니다.

three = samsung.merge(naver, how='outer').merge(usdkrw, how='outer') | shape: (128, 3)
Date (DatetimeIndex) Samsung (KRX) Naver (KRX) USDKRW (외환) 특징
2026-02-13 63,500.0 388,900.0 1,425.57 3개 자산 모두 정상 거래
2026-02-16 NaN NaN 1,430.00 국내 2종목 동시 NaN 발생!
2026-02-17 NaN NaN 1,430.00 국내 2종목 동시 NaN 발생!
2026-02-18 NaN NaN 1,427.63 국내 2종목 동시 NaN 발생!
2026-02-19 62,900.0 390,600.0 1,419.64 코스피 개장으로 전원 정상 거래 
# §500-13: 세 자산 마스터 파이프라인
three = (
    samsung[['Close']].rename(columns={'Close': 'Samsung'})
    .merge(naver[['Close']].rename(columns={'Close': 'Naver'}), left_index=True, right_index=True, how='outer')
    .merge(usdkrw[['Close']].rename(columns={'Close': 'USDKRW'}), left_index=True, right_index=True, how='outer')
)

# 올바른 순서로 완성: 가격 ffill 후 pct_change
returns_final = three.ffill().pct_change()
print(returns_final.loc['2026-02-13':'2026-02-19'])
