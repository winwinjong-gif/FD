# OpenDART 인증키 발급 흐름 화면

- `01-home.png` — https://opendart.fss.or.kr/  
  학생은 상단 메뉴에서 **인증키 신청/관리**를 클릭해 발급 절차를 시작합니다.

- `02-key-menu.png` — https://opendart.fss.or.kr/uat/uia/egovLoginUsr.do  
  계정이 있으면 로그인합니다. 계정이 없으면 상단 메뉴의 **인증키 신청/관리**에서 **인증키 신청**을 선택합니다.

- `03-signup.png` — https://opendart.fss.or.kr/uss/umt/EgovMberInsertView.do  
  학생은 약관을 확인한 뒤 회원가입 절차를 진행하여 인증키 신청을 위한 계정을 만듭니다.

- `04-login-required.png` — https://opendart.fss.or.kr/uat/uia/egovLoginUsr.do  
  인증키 관리에는 로그인이 필요합니다. 이 파일은 위 `02-key-menu.png`와 같은 로그인 화면이라 중복 이미지를 사용합니다. 로그인 후 본인 인증키가 보이는 화면은 캡처하지 않습니다.

- `05-usage-guide.png` — https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019016  
  학생은 개발가이드의 **공시정보 > 단일회사 주요계정**에서 API 요청 경로와 필수 파라미터를 확인합니다.
