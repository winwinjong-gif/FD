## GUI와 CLI — 두 가지 창구
학생이 "CLI가 뭐예요?"라고 물으면 정의보다 같은 일을 두 창구로 해 보는 장면을 먼저 보여 준다.
- **GUI (Graphical User Interface)** — ==그림 화면을 보고 눌러서 쓰는 방식==
	- 예: 증권사 앱에서 검색창에 "삼성전자" 입력 → 조회 → 기간 선택 → 차트 확인
	- 눈으로 보며 하나씩 누르니 처음 쓰는 프로그램도 쉽다. 대신 사람이 매 단계를 보고 눌러야 한다.
- **CLI (Command Line Interface)** — ==검정 화면(터미널)에 명령을 글자로 쳐서 컴퓨터에 일을 시키는 방식==
	- 결과도 그림이 아니라 글자(표)로 돌아온다.
	- 사람에게는 낯설지만, 글자를 읽고 쓰는 AI에게는 가장 편한 창구다.

같은 일 — "삼성전자 9월 종가" — 을 CLI로 하면 이렇게 된다 (덱 화면 5와 같다, 가격은 2026-10-08 실제 조회값).

```bash
# ① 종목 찾기
$ krx stock search 삼성전자
삼성전자  KR7005930003  KOSPI

# ② 9월 종가 가져오기 (날짜·종가 칸만)
$ krx stock list --market kospi --code KR7005930003 \
    --from 20260901 --to 20260930 --fields BAS_DD,TDD_CLSPRC
BAS_DD     TDD_CLSPRC
20260901   261000
…          …
20260930   268500
```

학생은 이 명령을 외우지 않는다. "삼성전자 9월 종가 알려줘"라고 말하면 AI가 도움말(`krx --help`)을 보고 이 두 줄을 대신 친다.

## 사실 박스 (2026-10-07 확인, 수업 직전 재확인)
- `krx-cli`는 **커뮤니티 오픈소스이며 KRX 공식 도구가 아니다.** 저장소: [github.com/kyo504/krx-cli](https://github.com/kyo504/krx-cli)
- 릴리스 v1.8.1 (2026-03-20) — [releases](https://github.com/kyo504/krx-cli/releases). "2026년 3월까지 개발과 릴리스가 확인되는 프로젝트"까지만 말한다.
- Node 20 이상, 설치 `npm install -g krx-cli`, 설치 이름 `krx-cli`, 실행 이름 `krx`.
- 키는 `KRX_API_KEY` 환경변수가 우선이고, 없으면 `krx auth set`으로 저장한 값을 쓴다 ([auth.ts](https://github.com/kyo504/krx-cli/blob/main/src/client/auth.ts)). **`.env` 파일을 스스로 읽지 않는다** — 그래서 설치 프롬프트에 "`.env`의 키를 환경변수로 불러오되 값은 출력하지 마"가 들어 있다.
- 같은 프로젝트가 CLI와 MCP 서버(`krx-mcp`)를 함께 제공한다 ([package.json](https://raw.githubusercontent.com/kyo504/krx-cli/main/package.json)). 오늘 실습은 CLI만 쓴다.

## KRX 서비스 이용신청 (키와 별도, 수업 전에 끝낸다)
API 키만 받아서는 데이터가 나오지 않는다. 키를 받은 뒤 **쓰려는 API마다 따로 이용신청**을 해야 하고, 신청하지 않았거나 기간이 끝난 API는 `Unauthorized API Call`로 거부된다.
**Mission 1–5에 필요한 신청 (모두 유가증권 = KOSPI, SK하이닉스도 KOSPI):**
- `유가증권 일별매매정보` — 날짜별 종가. Mission 1–5 전부 이것으로 계산한다.
- `유가증권 종목기본정보` — 종목 이름으로 코드를 찾을 때 쓴다.

#### 📖 신청 순서
1. [openapi.krx.co.kr](https://openapi.krx.co.kr) 로그인 → 상단 **서비스 이용** → 왼쪽 **주식** → 목록에서 `유가증권 일별매매정보` 클릭

![[fd05-krx-1-service-stock.png]]
*주식 카테고리의 API 8개. 오늘 쓰는 것은 1번(유가증권 일별매매정보)과 6번(유가증권 종목기본정보)이다.*
*API 이름 옆 영문 ID(`stk_bydd_trd`)가 krx-cli가 실제로 부르는 이름이다.*

2. 상세 화면 아래 **API 이용신청** → 기간과 신청 목적을 고르고 **확인**. `유가증권 종목기본정보`도 같은 방법으로 신청한다.

![[fd05-krx-2-apply-dialog.png]]
*기간은 1M·3M·6M·12M 중 고른다. 기본값 1M은 31일 뒤 끝나므로 학기 동안 쓰려면 6M 이상을 고른다.*
*신청 목적은 "개인 연구"로 둔다.*

3. **마이페이지 → 이용현황 → API 이용현황**에서 상태가 **승인**인지 확인한다.

![[fd05-krx-3-usage-status.png]]
*2026-10-08 교수 계정: 일별매매정보·종목기본정보는 신청 당일 바로 승인됐고, 한 건(코스닥 종목기본정보)은 승인대기로 남았다.*
*상태가 승인이고 사용기간이 남아 있어야 `krx auth status`에서도 승인으로 바뀐다.*

- 이전에 승인받았던 API도 **사용기간이 끝나면 다시 신청**해야 한다. 2026-10-07 리허설이 전부 거부된 원인이 이것이었다.

## 승인 확인의 한계
`krx auth status`는 키 설정과 서비스별 승인 상태를 보여 줄 뿐, Mission 1–5 데이터가 실제로 나온다는 보장이 아니다 ([README](https://raw.githubusercontent.com/kyo504/krx-cli/main/README.md)). 그래서 설치 화면의 ✓는 "연결 확인이 끝났다"는 뜻일 뿐이다. 미션 성공 여부는 수업 전 리허설과 수업 중 실제 출력으로만 판단한다. 승인되지 않은 서비스는 AI가 우회하거나 꾸며내지 않고 "쓸 수 없다"고 알려야 한다.

## 프롬프트 (학생에게 그대로 제시)
설치 프롬프트:

> krx-cli를 설치해서 사용할 수 있게 해줘. 먼저 https://github.com/kyo504/krx-cli 의 최신 README를 확인해서 현재 설치 방법과 필요한 환경을 확인하고 진행해. 프로젝트의 `.env`에서 `KRX_API_KEY`를 읽어 환경변수로 로드해서 사용하되, 키 값 자체는 화면·로그·답변에 출력하지 마. 설치가 끝나면 `krx-cli`가 실제 실행되는지와 현재 사용할 수 있는 KRX 서비스 범위를 확인해줘. API 키 같은 비밀정보는 외부에 유출하지 마.

미션 전 공통 두 문장:

> 미션을 수행하기 전에 요청에서 애매하거나 서로 충돌하는 부분이 있으면 임의로 가정하지 말고, 질문 도구를 사용해 가장 중요한 핵심 질문을 한 번에 하나씩 물어본 뒤 진행해줘.

> 현재 `krx-cli`가 지원하지 않거나 내가 승인받지 않은 기능이면 결과를 만들어내지 말고, 가능한 범위와 가장 가까운 대안을 알려줘.

- **Mission 1 — 하루 데이터 확인**: 삼성전자의 2026년 9월 30일 데이터를 `krx-cli`로 조회해줘. 현재 조회 가능한 가격 관련 항목만 간단한 표로 보여주고, 종목명·기준일·데이터 출처를 함께 적어줘.
- **Mission 2 — 최근 흐름 보기**: 삼성전자의 가장 최근 20거래일 데이터를 `krx-cli`로 조회해줘. 가능하면 종가 흐름을 간단히 요약하고, 그 기간의 최고 종가와 최저 종가를 알려줘. 마지막 데이터 기준일과 출처도 적어줘.
- **Mission 3 — 두 종목 비교**: 삼성전자와 SK하이닉스의 가장 최근 20거래일 데이터를 같은 기간으로 맞춰 `krx-cli`로 조회해줘. 첫 거래일 대비 마지막 거래일의 가격 변화율을 계산해서 간단한 표로 보여주고, 기준 기간과 데이터 출처를 적어줘.
- **Mission 4 — 최근 고점에서 얼마나 떨어졌나**: 삼성전자의 가장 최근 60거래일 데이터를 `krx-cli`로 가져와줘. 가능하면 그 기간의 최고 종가와 가장 최근 종가를 이용해서 최근 고점 대비 몇 % 낮은지 계산해줘. 계산에 사용한 날짜와 데이터 출처도 보여줘.
- **Mission 5 — 오늘 수업과 연결**: 삼성전자의 최근 데이터를 `krx-cli`로 가져와서 20일 이동평균과 60일 이동평균을 계산해줘. 가장 최근 시점의 두 값을 보여주고 어느 선이 더 높은지 한 문장으로 설명해줘. 계산에 필요한 데이터가 부족하거나 현재 도구로 가져올 수 없다면 그 이유를 알려줘. 기준일과 데이터 출처도 적어줘.

## 수업 전 리허설
- Mission 1–5를 교수 키로 먼저 실행한다. "최근 N거래일"은 에이전트가 날짜를 직접 계산해 `--from/--to`로 조회하므로, 실제로 받은 기간을 눈으로 확인한다.
- 2026-10-07 첫 리허설: 서비스 7개 모두 `Unauthorized API Call` → 원인은 키가 아니라 이용신청 기간 만료였다. 위 「KRX 서비스 이용신청」대로 다시 신청한 뒤 해결.
- 2026-10-08 재리허설 (이용신청 승인 후, krx-cli를 지운 상태에서 새 Claude Code 세션(Sonnet)에 설치 프롬프트 → 공통 두 문장 + Mission 1–5를 위 문장 그대로 입력) — 설치부터 다섯 미션까지 모두 성공했고, 키 값은 어느 출력에도 나오지 않았다:

| Mission | 결과 | 실제 기준 |
|---|---|---|
| 1 하루 데이터 | 성공 — 2026-09-30 삼성전자 종가 268,500원 (시가·고가·저가·등락률 포함) | 2026-09-30 |
| 2 최근 20거래일 | 성공 — 최고 285,500원(09-23), 최저 248,500원(09-15) | 2026-09-04 ~ 10-06 |
| 3 두 종목 비교 | 성공 — 삼성전자 +6.46%, SK하이닉스 +7.65% | 2026-09-04 ~ 10-06 |
| 4 고점 대비 | 성공 — 최고 285,500원(09-23) 대비 최근 272,000원은 −4.73% | 2026-07-08 ~ 10-06 |
| 5 이동평균 | 성공 — 20일선 266,425원 > 60일선 258,317원 | 2026-10-06 |

- AI는 "삼성전자"를 보통주(005930)로 보고 우선주를 뺐다고 밝혔고, 변화율·이동평균은 종가 기준 단순 계산이라는 가정을 스스로 적었다. 학생에게 "AI가 적은 가정"을 읽게 하면 좋다.
- 가장 최근 거래일 자료는 하루 늦게 올라온다(10-08 오전에 마지막 자료가 10-06). 학생 결과의 "마지막 기준일"이 어제·오늘이 아니어도 정상이다.
- 학생 키의 서비스 승인 상태를 사전에 공지한다. 승인이 없는 학생은 해당 미션을 "쓸 수 없다"는 AI의 답으로 확인한다.
- 학생 환경이 Copilot이면 공통 문장의 "질문 도구"가 실제로 동작하는지 미리 확인한다.

## 막힘 대처 (실험실 P3 막힘 카드 5종의 한 줄 처방)
| 막힘 | 처방 |
|---|---|
| Node 없음 | AI에게 Node가 있는지 확인하고 없으면 설치 방법부터 알려 달라고 한다. |
| 키 없음 | 키 값은 말하지 않고 `.env`에 `KRX_API_KEY` 줄이 있는지만 확인해 달라고 한다. |
| 서비스 미승인 | 자료를 꾸며내지 않고 쓸 수 있는 범위를 알려 달라고 한다. KRX 마이페이지 → API 이용현황에서 `유가증권 일별매매정보`가 승인이고 사용기간이 남았는지 본다. |
| 종목 검색이 빈 결과 | `krx stock search`는 전날 자료로 이름을 찾아서, 그날 자료가 아직 없으면 "No stocks found"가 난다. AI에게 "날짜를 정해 일별매매정보에서 종목명으로 찾아 줘"라고 부탁하면 된다. |
| 네트워크 | 연결을 확인한 뒤 같은 요청을 다시 한다. |
| 설치 권한 | AI가 알려 주는 대안을 확인하고, 막히면 교수에게 알린다. |

미션 중 키 오류가 나면 이렇게 부탁한다: "`.env`의 KRX_API_KEY를 다시 불러온 뒤 실행해 줘, 키 값은 출력하지 마." 허락 창에 키 값이 보이면 거절하게 한다.

## 🔖 핵심 요약
> [!summary] 🏆 이 노트를 마쳤다면?
>
> - [ ] 사람은 화면(GUI)을, 컴퓨터는 글자로 부탁하는 창구(CLI)를 편하게 쓴다는 것을 그림으로 설명할 수 있다.

> - [ ] 같은 질문 하나로 MCP와 CLI의 차이를 두 가지로 말할 수 있다 — 설명서를 언제 읽나(MCP는 처음부터 펼쳐 둠, CLI는 필요할 때 도움말을 찾아 봄)와 어디서 계산하나(MCP는 보통 결과를 AI가 그대로 읽고 계산, CLI는 컴퓨터가 계산해 AI는 결과 1줄만 읽음). MCP 도구가 요약·자르기 기능을 갖추면 MCP도 줄일 수 있다.
> - [ ] `krx-cli`가 커뮤니티 오픈소스이며 KRX 공식 도구가 아님을 말할 수 있다.
> - [ ] 키는 비밀번호처럼 다루고, 값이 화면이나 답변에 나오면 안 된다는 것을 안다.
> - [ ] 실습에서: 말로 부탁해서 `krx-cli`를 설치하고 Mission 1–5 중 실제로 결과가 나온 것을 확인한다.
