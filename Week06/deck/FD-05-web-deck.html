§200 두 선이 만나는 날

signal은 매일의 상태이고, cross는 상태가 바뀐 단 하루다

상태(signal) vs 사건(cross)
df["signal"] = df["ma20"] > df["ma60"]
prev = df["signal"].shift(1, fill_value=False)
df["cross"] = df["signal"] & ~prev
signal은 상태, cross는 바뀐 딱 하루(2025-02-20)입니다.

§300 미래참조편향 (Lookahead Bias)

shift(1)을 빼도 숫자는 거의 같다 — 그래서 버그가 안 보인다

삼성전자 2년 실측 누적수익 대조
  • 정상 정렬 (signal.shift(1)): +442.17%
  • shift(1) 누락 (position = signal): +445.77%
  • 크로스 당일 수익률을 하루 일찍 반영하는 타임머신 버그입니다.
  • 결과 숫자만 봐서는 버그를 알 수 없습니다 — 날짜 정렬을 직접 확인해야 합니다.
  • 442%는 성과 주장이 아닙니다(같은 기간 단순 보유 +321%). 전략 평가는 Week06.

§400 글자로 부탁하기 (CLI) 그림 예시

컴퓨터에는 글자로 일을 시키는 창구가 있다 — 터미널에서 자료를 찾는 모습

학생 → AI: "삼성전자 9월 종가 알려줘"
터미널 — AI가 대신 친다
# ① 종목 찾기
$ krx stock search 삼성전자
삼성전자 KR7005930003 KOSPI
# ② 9월 종가 가져오기
$ krx stock list --market kospi \
--code KR7005930003 \
--from 20260901 --to 20260930 \
--fields BAS_DD,TDD_CLSPRC
# 결과 (2026-10-08 실제 조회)
BAS_DD TDD_CLSPRC
20260901 261000
… …
20260930 268500
CLI = 글자로 명령해서 컴퓨터에 일을 시키는 방식
  • CLI (Command Line Interface): 검정 화면(터미널)에 명령 한 줄을 치면, 결과가 글자로 돌아온다
  • 예: 명령 두 줄 → ① 종목 찾기 ② 9월 종가 표
  • GUI의 다섯 번 클릭이 명령 두 줄로 바뀐다
  • 명령어는 우리가 외우지 않는다 — 말로 부탁하면 AI가 대신 친다

krx-cli를 설치해서 사용할 수 있게 해줘. 먼저 https://github.com/kyo504/krx-cli 의 최신 README를 확인해서 현재 설치 방법과 필요한 환경을 확인하고 진행해. 프로젝트의 .env에서 KRX_API_KEY를 읽어 환경변수로 로드해서 사용하되, 키 값 자체는 화면·로그·답변에 출력하지 마. 설치가 끝나면 krx-cli가 실제 실행되는지와 현재 사용할 수 있는 KRX 서비스 범위를 확인해줘. API 키 같은 비밀정보는 외부에 유출하지 마.
