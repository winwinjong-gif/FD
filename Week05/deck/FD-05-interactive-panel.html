[§100] 실험 1: 이동평균 계산과 지연

평균은 노이즈를 누르지만 항상 늦게 도착한다

💡 학습 포인트
  • 이동평균(SMA)의 대가 — 지연(Lag)
    • 가격의 일별 출렁임(노이즈)을 완화하여 매끄러운 추세를 보여줍니다.
    • 과거 N일의 평균이므로 급격한 가격 전환이나 반등을 항상 늦게 반영합니다.
  • 시작 구간의 숙명 — 워밍업 결측치(NaN)
    • 데이터 시작 시점부터 N - 1개 행은 평균을 낼 과거 데이터가 모자랍니다.
    • 이 구간에서는 값이 비어 있는 정직한 결측치(워밍업 NaN)가 필연적으로 발생합니다.
이동평균 윈도우 선택 (N)
이동평균이 늦게 반응하는 이유

이동평균은 최근 N일 종가의 평균입니다. 가격이 급히 바뀌어도 계산에 이전 날짜의 종가가 계속 포함되므로 평균선은 가격 변화보다 늦게 방향을 바꿉니다. 기간이 길수록 하루 변동은 더 완화되고, 방향 변화도 더 늦게 반영됩니다.

[§200] 실험 2: 크로스는 가설 — signal vs cross

signal은 매일의 상태이고 cross는 상태가 바뀐 딱 하루다

💡 학습 포인트
  • 상태(signal=True) vs 사건(cross=True)의 분리
    • 20일선이 60일선 위에 머무는 상태(signal)는 수개월간 지속될 수 있습니다.
    • 골든크로스는 그 상태가 시작된 단 하루(사건)에만 cross=True가 됩니다.
  • 시장 국면에 따른 유효성과 리스크
    • 추세장: 추세가 이어지는 국면에서는 이 신호가 효과적일 수 있습니다.
    • 박스권 횡보장: 두 선이 얽히며 계좌를 갉아먹는 휩쏘(Whipsaw)가 집중됩니다.

[§300] 실험 3: 신호와 실행의 하루 — shift(1) 해부

오늘 종가로 확인한 신호는 내일 장부터만 내 것이다

💡 학습 포인트
  • 신호 확정의 시간축
    • t일 15:30 장 종료 후 당일 종가가 확정되고, 저녁에 골든크로스 계산이 완료됩니다.
    • 따라서 포지션을 진입할 수 있는 가장 빠른 시점은 다음 거래일(t+1일) 09:00 개장입니다.
  • signal.shift(1)을 빠뜨리면 — 미래참조편향(타임머신 매매)
    • 아직 들고 있지도 않은 크로스 당일의 수익률을 백테스트가 훔쳐먹습니다.
    • 결과: 실전에서는 절대 재현할 수 없는 가짜 성과가 기록됩니다.

오답 3종 핵심 요약:
  • shift 누락: 아직 사지도 않은 크로스 당일의 수익률을 몰래 가져다 쓰는 타임머신 매매 — 그날이 상승이면 부풀리고 하락이면 오히려 깎습니다.
  • shift(-1): 내일의 결과를 오늘 장에 당겨오는 정반대의 치명적 누수.
  • fillna(0): 워밍업 59행의 모르는 상태(NaN)를 '신호 없음'으로 왜곡.

[§400] 실험 4: CLI·MCP와 KRX API 승인

에이전트가 무엇을 할 수 있는가는 받은 권한이 결정한다

💡 학습 포인트
  • 인터페이스 패러다임의 차이
    • 사람: GUI(마우스 클릭)가 직관적이고 자연스럽습니다.
    • 프로그램·에이전트: 구조화된 텍스트(CLI/JSON)가 가장 다루기 쉬운 인터페이스입니다.
  • 에이전트의 한계 — 승인 거버넌스(최소 권한 원칙)
    • 에이전트가 조회할 수 있는 데이터 범위는 모델의 성능보다 API 키에 승인된 서비스 범위로 결정됩니다.
    • Unauthorized API Call(에러 6): 해당 서비스 승인이 없는 API 요청은 거절됩니다.
